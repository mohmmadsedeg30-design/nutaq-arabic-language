# نُطْق — لغة برمجة عربية قابلة للتوسّع

**نُطْق** مشروع لغة برمجة عامة الغرض تضع العربية في قلب الصياغة وتجربة التطوير. يقدّم هذا المستودع الإصدار `0.3.0`: مفسّرًا فعليًا مبنيًا على محلّل معجمي ومحلّل نحوي وشجرة صياغة مجردة وبيئات نطاق معجمية، ومنصة ويب مدمجة للمسارات والقوالب وواجهات JSON، ومكتبة بيانات محلية للوحدات والملفات وJSON وSQLite. ليست نُطْق مجرد تحويل كلمات عربية إلى لغة أخرى؛ فجميع الكلمات المحجوزة ورسائل التشخيص والأمثلة عربية.

> **نُطْق 0.3 لغة شاملة وظيفيًا للتطوير المحلي والنماذج والتطبيقات الصغيرة والمتوسطة.** تدعم البرمجة المنظمة بالصفوف، ومعالجة الأخطاء، والوحدات، وتطبيقات الويب الديناميكية وقاعدة بيانات محلية. لكنها لا تعزل تنفيذ الشيفرات غير الموثوقة ولا تقدّم بعدُ مصادقة أو جلسات أو حماية CSRF أو إدارة أسرار؛ لذلك لا ينبغي نشرها مكشوفة على الإنترنت قبل إضافة تلك الطبقات ومراجعتها أمنيًا.

| المكوّن | ما يقدمه |
|---|---|
| `nutaq/core.py` | المحلّل المعجمي، المحلّل النحوي، شجرة الصياغة، المفسّر والمكتبة المعيارية. |
| `nutaq/cli.py` | تشغيل ملفات نُطْق، فحصها نحويًا، عرض رموزها، ووضع تفاعلي بسيط. |
| `nutaq/web.py` | خادم HTTP والمسارات والقوالب والملفات الثابتة وواجهات JSON. |
| `nutaq/stdlib.py` | JSON والملفات المقيدة بمشروع التطبيق وSQLite وعمليات القوائم. |
| `مواصفات_نطق_0_1.md` | مرجع الصياغة والدلالات التنفيذية للغة الأساسية. |
| `معمارية_ويب_نطق_0_2.md` | مرجع تفصيلي لواجهة الويب وحدودها الأمنية. |
| `مواصفات_الإصدار_الشامل_0_3.md` | مرجع الميزات الموسعة للوحدات والصفوف والاستثناءات والبيانات. |
| `أمثلة/تحليل_درجات.نطق` | برنامج متكامل لتحليل بيانات درجات. |
| `مثال_ويب/` | مشروع موقع عربي كامل، مع قوالب وCSS وواجهة JSON. |
| `مثال_مهام/` | تطبيق CRUD للمهام مع SQLite وPOST وPATCH وDELETE. |
| `tests/` | اختبارات الانحدار الشاملة للغة والمكتبة والويب. |

## البدء السريع

يتطلب المشروع **بايثون 3.10 أو أحدث**. لا يحتاج إصدار النواة إلى أي مكتبات خارجية.

```bash
cd nutaq
python3 -m nutaq.cli أمثلة/تحليل_درجات.نطق
```

ولإنشاء الأمر التنفيذي `nutaq` في بيئتك الحالية، ثبّت الحزمة محليًا ثم شغّل ملفًا:

```bash
python3 -m pip install -e .
nutaq أمثلة/تحليل_درجات.نطق
```

| الأمر | النتيجة |
|---|---|
| `python3 -m nutaq.cli ملف.نطق` | ينفذ البرنامج. |
| `python3 -m nutaq.cli --تحقق ملف.نطق` | يحلل البرنامج دون تشغيله. |
| `python3 -m nutaq.cli --رموز ملف.نطق` | يعرض الرموز المعجمية ومواقعها. |
| `python3 -m nutaq.cli` | يفتح الوضع التفاعلي للتعليمات ذات السطر الواحد. |
| `python3 -m unittest discover -s tests -v` | يشغّل اختبارات الانحدار. |

## الحجم والخفة

صُممت نُطْق لتبقى صغيرة وسهلة النقل. يعتمد المفسّر ومنصة الويب وSQLite على **مكتبة بايثون القياسية فقط**، ولا توجد حزم خارجية أو أطر ضخمة أو ملفات مبنية ضمن المستودع. تستبعد قواعد النشر قواعد البيانات المحلية والسجلات والبيئات الافتراضية ومخرجات بايثون، فلا يرتفع حجم المستودع ببيانات التشغيل الشخصية.

| القرار | الأثر |
|---|---|
| دون تبعيات خارجية | تشغيل سريع بعد وجود بايثون، ودون تنزيل حزم إضافية. |
| قاعدة SQLite محلية عند الحاجة | لا تُضم أي قاعدة بيانات في الكود المصدري. |
| أصول نموذجية نصية فقط | لا توجد صور أو حزم واجهات كبيرة. |
| استبعاد مخرجات التطوير | يبقى المستودع نظيفًا وخفيفًا عند الاستنساخ. |

## أول برنامج

```نطق
دع الاسم = "العالم"
اطبع("مرحبًا يا " + الاسم)

دالة مربع(عدد) {
    أرجع عدد ^ 2
}

لكل ن في نطاق(1، 6) {
    اطبع(نص(ن) + " تربيعها " + نص(مربع(ن)))
}
```

يمكن استعمال الأرقام العربية الهندية أو اللاتينية، والفاصلة العربية `،` أو اللاتينية `,`، والفاصلة المنقوطة العربية `؛` أو اللاتينية `;`. وتُقبل أسماء عربية أو لاتينية مثل `المجموع_2026` و`total_2`.

## ملامح اللغة

تستخدم نُطْق الأقواس المعقوفة للكتل كي تكون البنية واضحة في النصوص العربية والبيئات التي تختلط فيها اتجاهات الكتابة. تنتهي التعليمة بنهاية السطر عادةً، ويمكن استعمال الفاصلة المنقوطة عند وضع أكثر من تعليمة في سطر واحد.

| المجال | الصياغة | مثال |
|---|---|---|
| تعريف متغير | `دع اسم = قيمة` | `دع عدد_الطلاب = 30` |
| شرط | `إذا شرط { … } وإلا { … }` | `إذا النتيجة >= 50 { اطبع("ناجح") }` |
| حلقة شرطية | `بينما شرط { … }` | `بينما ن < 10 { ن = ن + 1 }` |
| مرور | `لكل اسم في عناصر { … }` | `لكل عنصر في قائمة { اطبع(عنصر) }` |
| دالة | `دالة اسم(معاملات) { … }` | `دالة جمع(أ، ب) { أرجع أ + ب }` |
| قائمة | `[قيمة، …]` | `دع ألوان = ["أحمر"، "أزرق"]` |
| قاموس | `{مفتاح: قيمة، …}` | `دع طالب = {"الاسم": "سارة"}` |
| فهرسة | `قيمة[فهرس]` | `اطبع(ألوان[0])` |

### الوحدات والصفوف والاستثناءات

تسمح الوحدات بفصل الوظائف في ملفات `.نطق` محلية: `استورد "مكتبات/حساب.نطق" ك حساب` ثم `حساب.دالة_مفيدة()`. كما يدعم الإصدار صفوفًا وطرائق مرتبطة وحقولًا عبر `صنف` و`ذات`، إضافة إلى معالجة الأخطاء ببنية `حاول` و`التقط` و`أخيرًا` و`ارم`.

```نطق
صنف عداد {
    دالة تهيئة(ذات، بداية) { ذات.قيمة = بداية }
    دالة زد(ذات) { ذات.قيمة = ذات.قيمة + 1; أرجع ذات.قيمة }
}

حاول {
    دع ع = عداد(0)
    اطبع(ع.زد())
} التقط مشكلة {
    اطبع(مشكلة.رسالة)
}
```

### الأنواع والعوامل

يدعم المفسّر الأعداد الصحيحة والعشرية، والنصوص، والمنطقيات `صحيح` و`خطأ`، والقيمة `عدم`، والقوائم والقواميس والدوال. تتضمن العوامل الحسابية `+ - * / % ^`، والمقارنات `== != < <= > >=`، والمنطق قصير الدارة `و أو ليس`. يُستخدم `+` للأعداد أو النصوص أو القوائم المتجانسة في النوع، ولا يحوّل القيم تلقائيًا إلى نص؛ استخدم `نص(قيمة)` عند بناء رسالة.

```نطق
دع درجات = {"سارة": 98، "ليان": 91}
إذا درجات["سارة"] > 95 و ليس خطأ {
    اطبع("نتيجة مميزة")
}
```

### الدوال المضمنة

| الدالة | الاستخدام |
|---|---|
| `اطبع(قيم…)` | تعرض القيم في سطر واحد. |
| `أدخل(رسالة?)` | تقرأ سطرًا نصيًا من المستخدم. |
| `طول(قيمة)` | طول نص أو قائمة أو قاموس. |
| `نطاق(نهاية)` أو `نطاق(بداية، نهاية، خطوة?)` | قائمة أعداد صحيحة لعمليات المرور. |
| `عدد(قيمة)` و`نص(قيمة)` و`نوع(قيمة)` | تحويل وتمييز الأنواع. |
| `أضف(قائمة، قيمة)` و`احذف(قائمة، فهرس)` | تعديل قائمة. |
| `مفاتيح(قاموس)` و`قيم(قاموس)` | الحصول على قوائم المفاتيح أو القيم. |

## البيانات والملفات وقواعد البيانات

توفر نُطْق `إلى_JSON` و`من_JSON` لتحويل البيانات، و`اقرأ_ملف` و`اكتب_ملف` و`يوجد` لملفات UTF-8 داخل مجلد المشروع فقط. تمنع الدوال مسارات مثل `../` التي تحاول الخروج من التطبيق. وتُبنى التطبيقات ذات التخزين الدائم باستخدام SQLite:

```نطق
دع قاعدة = افتح_قاعدة("بيانات/موقعي.db")
قاعدة.نفذ("CREATE TABLE IF NOT EXISTS رسائل (معرف INTEGER PRIMARY KEY, نص TEXT)")
قاعدة.نفذ("INSERT INTO رسائل (نص) VALUES (?)"، ["مرحبًا"])
دع رسائل = قاعدة.نفذ("SELECT معرف, نص FROM رسائل")
اطبع(رسائل[0].نص)
قاعدة.أغلق()
```

> استخدم المعامل الثاني لقيمة `نفذ` لتمرير البيانات، ولا تدمج مدخلات المستخدم في نص SQL. وهذا يحقق فصلاً واضحًا بين الاستعلام والقيم في تطبيقاتك.

## بناء موقع إلكتروني كامل

يضع مشروع الموقع في مجلد مستقل ثم يشغّل الملف الرئيسي. يبحث المشغّل عن المجلدين `قوالب/` و`static/` نسبة إلى الملف الذي تشغّله، لذلك تبقى أصول كل موقع معزولة وواضحة.

```bash
python3 -m nutaq.cli مثال_ويب/التطبيق.نطق
```

بعد التشغيل، افتح `http://127.0.0.1:8000`. يحتوي المشروع النموذجي على صفحة متجر عربية، وملف CSS ثابت، ومسار تواصل يتلقى JSON، وواجهتي JSON هما `/api/المنتجات` و`/api/المنتجات/{معرف}`. ولتجربة تطبيق متكامل مع التخزين، شغّل `python3 -m nutaq.cli مثال_مهام/التطبيق.نطق`؛ يعرض مهامًا محفوظة في SQLite ويقدّم مسارات `GET` و`POST` و`PATCH` و`DELETE`.

### واجهة الويب بالعربية

| الدالة | الاستخدام |
|---|---|
| `مسار(طريقة، نمط، معالج)` | تربط دالة نُطْق بطلب HTTP؛ تدعم `GET` و`POST` و`PUT` و`PATCH` و`DELETE` و`HEAD` و`OPTIONS`. |
| `صفحة(HTML، حالة?، رؤوس?)` | تعيد HTML بترميز UTF-8. |
| `استجابة_نص(محتوى، حالة?، رؤوس?)` | تعيد استجابة نصية. الاسم منفصل عمدًا عن `نص`، دالة تحويل القيم إلى نص. |
| `JSON(بيانات، حالة?)` | تعيد بيانات JSON عربية دون تحويل الحروف إلى رموز هروب. |
| `إعادة_توجيه(وجهة، حالة?)` | تنشئ إعادة توجيه؛ الحالة الافتراضية 302. |
| `قالب(اسم، سياق?)` | يعرض قالبًا من `قوالب/` ويهّرب القيم افتراضيًا. |
| `ثابت(بادئة، مجلد?)` | يقدّم أصول CSS وJavaScript والصور من مجلد محلي. |
| `شغّل(منفذ?، مضيف?)` | يبدأ الخادم؛ القيمة الافتراضية `127.0.0.1:8000`. |

يستقبل معالج المسار قاموسًا واحدًا باسم `طلب` يحوي `طريقة` و`مسار` و`معاملات` و`استعلام` و`رؤوس` و`نص` و`بيانات`. تنشأ `بيانات` تلقائيًا من جسم JSON أو نموذج `application/x-www-form-urlencoded` عندما يكون صالحًا.

```نطق
دالة ملف_تعريف(طلب) {
    دع معرف = طلب["معاملات"]["معرف"]
    أرجع JSON({"معرف": معرف، "اللغة": "نُطْق"})
}

دالة الرئيسية(طلب) {
    أرجع صفحة(قالب("الرئيسية.html"، {"العنوان": "موقعي العربي"}))
}

ثابت("/static")
مسار("GET"، "/"، الرئيسية)
مسار("GET"، "/api/ملف/{معرف}"، ملف_تعريف)
شغّل(8000)
```

### القوالب

يستبدل `{{اسم}}` بقيمة مهربة في HTML، ولذلك يكون ملائمًا لمدخلات المستخدم والنصوص العادية. أما `{{{اسم}}}` فيدرج HTML خامًا ويجب قصره على المحتوى الذي أنشأه تطبيقك ويثق به، كما في بطاقات المنتجات التي يولّدها المثال. يحجب المشغّل مسارات القوالب والملفات الثابتة التي تحاول الخروج من مجلد المشروع.

## التشخيص والأخطاء

يتضمن كل خطأ اسم الفئة ورقم السطر والعمود، مما يجعل التصحيح مباشرًا. على سبيل المثال، يشير `خطأ_اسم (سطر 4، عمود 7)` إلى اسم غير معرّف في ذلك الموقع. تشمل الفئات `خطأ_رمزي` و`خطأ_نحوي` و`خطأ_اسم` و`خطأ_نوع` و`خطأ_فهرس` و`خطأ_تنفيذي`.

```text
خطأ_اسم (سطر 1، عمود 7): الاسم «مجهول» غير معرّف.
```

## الجودة والتحقق

تغطي اختبارات المشروع الحساب والأرقام العربية الهندية والقوائم والقواميس والفهرسة والإسناد والنطاقات والدوال التراجعية والنطاقات المعجمية والحلقات و`توقف` و`تابع` والمنطق قصير الدارة وتشخيص الأخطاء. كما تغطي الصفوف والخصائص والطرائق والوحدات والاستثناءات وJSON والملفات المحصورة في المشروع وSQLite بمعاملات، وتتحقق من القوالب الآمنة والمسارات الديناميكية وطرق `POST` و`PATCH` و`DELETE` والملفات الثابتة وحالة 404. شُغّلت بنجاح **28 حالة اختبار** في هذا الإصدار، إضافة إلى دورة CRUD حقيقية لتطبيق المهام عبر HTTP.

## خارطة التوسّع

يحافظ تنظيم النواة على إمكان تطوير نُطْق على مراحل، بدل تكديس الميزات في مفسّر واحد. الأولويات التالية هي المصادقة والجلسات وCSRF وإدارة الأسرار للويب، والوحدات ذات التصدير الصريح والحزم، وصفوف أكثر ثراءً، ومفسّر تفاعلي يدعم الكتل متعددة الأسطر، ثم بايت كود وآلة افتراضية للأداء، وأخيرًا مدير حزم وتلوين صياغة وإضافات للمحررات.

| المرحلة التالية | القيمة المتوقعة |
|---|---|
| المصادقة والجلسات وCSRF | إتاحة تطبيقات حسابات مستخدمين منشورة بأمان. |
| حزم وتصدير صريح | تنظيم المكتبات المحلية والمشاريع الكبيرة. |
| صفوف وسجلات متقدمة | وراثة وواجهات وأنواع أوسع عند الحاجة. |
| قاعدة بيانات ومصادقة | تحويل نموذج الويب إلى تطبيقات حسابات ومحتوى دائمة. |
| بايت كود وآلة افتراضية | تقليل كلفة تفسير شجرة الصياغة وتحسين الأداء. |
| أدوات المطوّر | مفسّر تفاعلي متعدد الأسطر، ملوّن صياغة ومدير حزم. |
